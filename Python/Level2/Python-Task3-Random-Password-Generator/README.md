# 🔐 Advanced Password Generator

A modern GUI-based Password Generator built using Python and Tkinter.  
This application creates strong, secure passwords with multiple customization options.

---

## 🚀 Features
✔ Generate strong and secure passwords  
✔ Copy password to clipboard instantly  
✔ Save passwords to a file  
✔ Password strength indicator (Weak / Medium / Strong)  
✔ Dark & Light mode toggle 🌙☀️  
✔ Password history (last 5 passwords)  
✔ Option to include/exclude symbols, numbers, etc.  

---

## 🛠️ Tech Stack
- Python 🐍  
- Tkinter (GUI)  
- Pyperclip
