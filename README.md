# BMI Calculator (OIBSIP Task 2)

## 📌 Description
A Python-based BMI Calculator that calculates Body Mass Index and tracks user health data.

## 🚀 Features
- BMI Calculation
- Data stored in SQLite database
- CSV export
- Visualization using graphs

## 🛠️ Technologies Used
- Python
- SQLite
- Matplotlib

## ▶️ How to Run
1. Install dependencies:
   pip install -r requirements.txt

2. Run the program:
   python main.py
